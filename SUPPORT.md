# Support

## Questions and usage help

Open a GitHub Discussion when available, or create a question issue with:

- operating system and Python version;
- installation method;
- exact command;
- complete error text with secrets removed;
- whether demo mode works.

## Bugs

Use the bug report form:

https://github.com/mastaan66/multi-agent-coding-tool/issues/new/choose

## Security

Do not report vulnerabilities in public issues. Follow [SECURITY.md](SECURITY.md).
