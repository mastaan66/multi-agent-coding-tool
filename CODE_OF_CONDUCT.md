# Code of Conduct

AI Software Factory is an open-source project where contributors should be able to
participate without harassment or intimidation.

## Expected behavior

- Be respectful, patient, and constructive.
- Critique ideas and code, not people.
- Assume good intent while still addressing harmful impact.
- Welcome contributors with different backgrounds and experience levels.
- Respect privacy and do not publish another person's private information.
- Accept maintainer decisions about project scope and moderation.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized attention, deliberate disruption,
doxxing, and sustained personal attacks are not tolerated in project spaces.

## Reporting

Report conduct concerns privately to the repository maintainers through the contact
options on the maintainer's GitHub profile. Do not open a public issue containing
sensitive personal information.

Maintainers may edit or remove contributions and may temporarily or permanently ban
participants whose behavior is harmful to the community.
